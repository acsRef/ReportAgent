# ReportAgent 智能分析工作台设计

## 目标

将现有“聊天页 + 独立运行页 + 固定格式报告页”重构为一个统一的智能分析工作台原型。用户通过业务语言提出问题，后端 Agent 根据数据特征决定报告结构，前端只负责动态渲染 ReportBlock，并允许用户通过继续对话调整分析。

## 产品原则

1. 报告结构由 Agent 和数据特征决定，不由前端提供固定格式切换器。
2. 先呈现业务结论，再呈现指标、趋势、对比、异常和明细证据。
3. 对话是调整报告的主要入口，按钮建议只是低成本快捷方式。
4. Agent Runtime 是可选的可解释信息，不与业务结论争夺注意力。
5. 保持较高分析信息密度，但通过层级、留白与聚焦模式控制认知负担。

## 页面结构

### 顶部栏

包含产品标识、当前数据域、连接状态，以及保存、导出和报告聚焦操作。顶部栏用于全局状态与报告级动作，不重复页面导航。

### 左侧栏

只承担工作上下文管理：

- 新建分析
- 最近会话
- 收藏报告

模板和完整历史作为次级入口，不在多个区域重复出现。

### 中央工作区

同一画布中保留用户问题、Agent 理解和动态报告，避免在 Chat / Running / Report 三个孤立页面间跳转。

报告的信息层级为：

1. 一句话核心结论
2. 关键指标与变化
3. 主趋势和结构对比
4. 异常与原因解释
5. 数据明细
6. 下一步分析建议

报告由后端动态返回的区块构成，例如 KPI、趋势图、对比图、明细表、洞察和异常提醒。不同问题可以返回不同区块组合。

### 右侧分析助手

默认包含：

- 本次报告的分析结构
- Agent 推荐的下一步分析
- 当前筛选条件与数据范围
- 可折叠的执行轨迹

点击建议后，通过对话语义模拟报告调整，例如增加华南对比、切换到月度趋势或突出异常。

## 关键交互

- 点击左侧会话切换分析上下文。
- 点击“聚焦报告”隐藏左右栏，进入沉浸式报告查看。
- 点击建议芯片，生成一条用户调整请求并更新报告结构或内容。
- 用户输入自然语言，例如“增加华南区域对比”，报告增量更新并显示更新提示。
- 执行轨迹默认收起，展开后展示 Security Guard、Data Agent、SQL Agent 和 Report Agent 状态。
- 明细表默认展示有限行，可展开或收起。
- 导出按钮提供轻量反馈，原型不生成真实文件。

## 视觉方向

采用“编辑部式数据工作台”：浅色纸张感画布、深海军蓝结构色、青绿色分析强调色和少量琥珀色异常提示。避免普通后台模板的均匀卡片堆叠，通过编号章节、结论带、细线分隔和不对称图表布局建立报告叙事。

字体使用中文友好的宋体展示标题与无衬线正文组合。图表采用轻网格、低饱和系列和明确的数据标注。动效集中于初次载入、报告更新和侧栏/轨迹展开，不使用无意义的持续动画。

## 原型范围

本次只创建独立纯 HTML/CSS/JavaScript 原型，不接入后端，不修改 React 应用。原型使用静态业务数据模拟完整分析闭环，用于确认布局、视觉和交互方向。

## 后续落地边界

React 落地时继续沿用现有 SSE、Zustand 和 ReportBlock registry。新的页面结构应重组现有组件，而不是把报告格式写死在前端。建议调整应最终转换成普通 chat 请求，由后端重新规划或增量生成报告区块。
